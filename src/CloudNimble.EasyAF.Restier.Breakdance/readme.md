# EasyAF.Restier.Breakdance

Breakdance test-host helpers for EasyAF Restier APIs.

## Install

```bash
dotnet add package EasyAF.Restier.Breakdance
```

## Usage

Reference this package from a test project and use the Breakdance host pattern to boot a Restier API in-process (HTTP, configuration, and EasyAF services) without standing up a full server.

Requires Breakdance and `EasyAF.Restier`.
