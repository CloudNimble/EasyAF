## Summary

Instantiates the .NET SDK's built-in C# project templates (`classlib`, `web`, `console`)
in-process through Microsoft.TemplateEngine, without spawning `dotnet new`.

## Remarks

Template packages are discovered the same way the SDK's own `BuiltInTemplatePackageProvider` finds them:
`{dotnetRoot}/templates/{version}/*.nupkg`, where `{version}` is the highest folder whose major version
matches the requested target framework. Template post-actions (such as restore) are not executed.

### <Icon icon="function" iconType="duotone" color="#E0EC32" size={24} className="mr-2" /> CreateProjectAsync

Creates a project from an SDK template.

#### Syntax

```csharp
public System.Threading.Tasks.Task<string> CreateProjectAsync(string shortName, string projectName, string outputDirectory, bool overwrite = false, System.Threading.CancellationToken cancellationToken = null)
```

#### Parameters

| Name | Type | Description |
|------|------|-------------|
| `shortName` | `string` | The template short name: `classlib`, `web`, or `console`. |
| `projectName` | `string` | The project name, which becomes the .csproj file name and default namespace. |
| `outputDirectory` | `string` | The directory the project is written to. It must not exist or must be empty unless *overwrite* is set. |
| `overwrite` | `bool` | When [`true`](https://learn.microsoft.com/dotnet/csharp/language-reference/builtin-types/bool), files already in *outputDirectory* may be replaced. The caller is expected to have asked the user first. |
| `cancellationToken` | `System.Threading.CancellationToken` | A token to cancel the operation. |

#### Returns

Type: `System.Threading.Tasks.Task<string>`
The full path of the created .csproj file.

#### Exceptions

| Exception | Description |
|-----------|-------------|
| `TemplateNotFoundException` | Thrown when no matching C# project template exists on the machine. |
| `InvalidOperationException` | Thrown when *outputDirectory* already contains files and *overwrite* is [`false`](https://learn.microsoft.com/dotnet/csharp/language-reference/builtin-types/bool), or when the template engine reports a failure. |
