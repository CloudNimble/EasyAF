## Summary

Applies a [ScaffoldProject](/api-reference/CloudNimble/EasyAF/Tools/Scaffolding/ScaffoldProject) description to a project file freshly created from an SDK template.

## Remarks

The SDK templates always add `ImplicitUsings` and `Nullable` (the class library and console templates through
computed symbols a caller cannot set, the web template unconditionally), so they are removed here and the solution's
`Directory.Build.props` decides. Reference groups are written immediately after the leading `PropertyGroup`,
`PackageReference` first, then `ProjectReference`, entries alphabetical, versions as attributes.
