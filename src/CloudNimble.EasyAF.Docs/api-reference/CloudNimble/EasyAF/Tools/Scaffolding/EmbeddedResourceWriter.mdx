## Summary

Renders text files embedded in an assembly, replacing `{{Token}}` placeholders, and writes them to disk.

## Remarks

Resources are expected to use path-preserving logical names (for example `Resources/Api/Program.cs`) so that
folder names containing dots are not confused with nested folders. Tokens are replaced in a single pass, so a token
value that itself looks like a token is written literally. A placeholder with no matching token is an error rather
than something to ship. Line endings are normalized to [NewLine](https://learn.microsoft.com/dotnet/api/system.environment.newline).
