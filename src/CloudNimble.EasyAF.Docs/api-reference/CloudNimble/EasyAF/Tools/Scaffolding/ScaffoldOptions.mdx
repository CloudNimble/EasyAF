Initializes a new instance of the [ScaffoldOptions](/api-reference/CloudNimble/EasyAF/Tools/Scaffolding/ScaffoldOptions) class.

#### Syntax

```csharp
public ScaffoldOptions(string namespace, System.Version toolVersion, int dotNetVersion = 11, bool includeApi = true, bool includeMessageBus = true, bool includeRuntime = true, bool webJob = false, bool toolIsPrerelease = false)
```

#### Parameters

| Name | Type | Description |
|------|------|-------------|
| `namespace` | `string` | The solution namespace; every dot-separated segment must be a C# identifier. |
| `toolVersion` | `System.Version` | The version of the EasyAF tool creating the solution; its major version is the EasyAF version referenced. |
| `dotNetVersion` | `int` | The .NET major version to target: `10` or `11`. |
| `includeApi` | `bool` | Whether to create the `.Api` project. |
| `includeMessageBus` | `bool` | Whether to create the `.MessageBus.*` projects. |
| `includeRuntime` | `bool` | Whether to create the `.MessageBus.Runtime` project. |
| `webJob` | `bool` | Whether to stamp Azure WebJob publish metadata on the runtime. |
| `toolIsPrerelease` | `bool` | Whether the EasyAF tool is a prerelease, so EasyAF packages float to prereleases. |

#### Exceptions

| Exception | Description |
|-----------|-------------|
| `ArgumentNullException` | Thrown when *toolVersion* is [`null`](https://learn.microsoft.com/dotnet/csharp/language-reference/keywords/null). |
| `ArgumentException` | Thrown when an argument is invalid or the flags conflict. |
