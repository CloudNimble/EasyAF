## Summary

Creates a new EasyAF solution: the Core, Data, Business, Api, MessageBus, and Tests projects, referenced the way EasyAF expects,
with the solution-level build files and an `.slnx`.

## Remarks

Projects are created in-process from the SDK's own `classlib`, `web`, and `console` templates, then configured with
EasyAF project types, package references, and project references. EasyAF files (Program.cs, appsettings, test bases) are written over
the template output.

`new` only creates and links projects. It doesn't connect a database, restore, build, or start any process; `dotnet easyaf init`
          connects a database afterwards.
