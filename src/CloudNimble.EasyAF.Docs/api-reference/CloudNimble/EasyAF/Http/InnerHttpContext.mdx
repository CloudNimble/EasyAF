## Summary

Copies origin, identity, and headers from an outer [HttpContext](https://learn.microsoft.com/dotnet/api/microsoft.aspnetcore.http.httpcontext) onto an inner
in-process request so the inner pipeline sees the public URL and the same user.

## Remarks

The caller constructs the inner [HttpContext](https://learn.microsoft.com/dotnet/api/microsoft.aspnetcore.http.httpcontext) (typically `new DefaultHttpContext()` in
an ASP.NET Core app, or [IFeatureCollection)](https://learn.microsoft.com/dotnet/api/microsoft.aspnetcore.http.ihttpcontextfactory.create(microsoft.aspnetcore.http.features.ifeaturecollection))). This type stays on
`Microsoft.AspNetCore.Http.Abstractions` and does not construct a context.

## Examples

```csharp
var inner = new DefaultHttpContext
{
    RequestServices = scope.ServiceProvider,
    RequestAborted = cancellationToken
};
InnerHttpContext.CopyFromOuter(inner, outer);
InnerHttpContext.ConfigureRequest(inner, "GET", "/odata/Customers", QueryString.Empty);
inner.Request.Headers["Accept"] = "application/json";
inner.Response.Body = new MemoryStream();
```

### <Icon icon="thumbtack" iconType="duotone" color="#E0EC32" size={24} className="mr-2" /> CopyFromOuter

Copies scheme, host, path base, user, and non-skipped headers from *outer* onto
*inner*. When *outer* is [`null`](https://learn.microsoft.com/dotnet/csharp/language-reference/keywords/null), uses
`http` / `localhost` and an empty principal.

#### Syntax

```csharp
public static void CopyFromOuter(Microsoft.AspNetCore.Http.HttpContext inner, Microsoft.AspNetCore.Http.HttpContext outer)
```

#### Parameters

| Name | Type | Description |
|------|------|-------------|
| `inner` | `Microsoft.AspNetCore.Http.HttpContext` | The inner context to fill. |
| `outer` | `Microsoft.AspNetCore.Http.HttpContext` | The incoming context, or [`null`](https://learn.microsoft.com/dotnet/csharp/language-reference/keywords/null) when there is no outer request. |

#### Exceptions

| Exception | Description |
|-----------|-------------|
| `ArgumentNullException` | Thrown when *inner* is [`null`](https://learn.microsoft.com/dotnet/csharp/language-reference/keywords/null). |

#### Remarks

Scheme, host, and path base come from the outer request so generated links match the public URL.
Other request headers are copied except hop-by-hop, entity-body, and HTTP conditionals
(see [InnerHttpContext.SkippedRequestHeaders](/api-reference/CloudNimble/EasyAF/Http/InnerHttpContext#skippedrequestheaders)).
