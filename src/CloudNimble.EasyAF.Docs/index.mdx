## How the parts fit together

- **Blazor UI (BlazorEssentials)**: the front end people use. It reaches your data through the REST API. See [/blazoressentials/guides](/blazoressentials/guides).
- **AI agent (OData MCP)**: OData MCP points an agent at the same live OData API. See [https://si.nimbleapps.cloud](https://si.nimbleapps.cloud).
- **REST API (EasyAF.Restier)**: a Restier host that exposes your entities over OData. See [/restier](/restier).
- **Managers (EasyAF.Business)**: one per entity. They wrap create, update, and delete, fill audit fields, and provide lifecycle hooks. See [/guides/business-layer](/guides/business-layer).
- **Async events (SimpleMessageBus)**: the API and every manager receive a message publisher. See [/simplemessagebus](/simplemessagebus).
- **Data (EasyAF.Data.EFCore)**: an Entity Framework DbContext generated for your schema. See [/guides/table-design](/guides/table-design).
- **Database**: SQL Server or PostgreSQL. The CLI reads the schema and generates the layers above it.
- **CLI and code generation (`dotnet easyaf`)**: scaffolds the solution and generates entities, the DbContext, managers, and the API. See [/quickstart](/quickstart).
- **Core (EasyAF.Core)**: entities, interfaces, observable objects, and intervals. It works on its own in any .NET project.
- **Testing (Breakdance)**: the scaffolded solution includes Breakdance test projects. See [/breakdance](/breakdance).
- **XML (XmlEssentials)**: a standalone XML library. See [/xmlessentials](/xmlessentials).

  <p className="eaf-sub">These are the commands from the <a href="/quickstart">quickstart</a>, which explains each one.</p>
  <div className="eaf-steps">

<Steps>
  <Step title="Install the CLI">
    ```bash
    dotnet tool install EasyAF --global
    ```
  </Step>
  <Step title="Create a solution">
    ```bash
    dotnet easyaf new CloudNimble.Contoso
    ```
  </Step>
  <Step title="Connect a database">
    ```bash
    dotnet easyaf init -c "appsettings.json:ConnectionStrings:DefaultConnection" -x ContosoContext -p SqlServer
    ```
  </Step>
  <Step title="Generate from your schema">
    ```bash
    dotnet easyaf database generate --context-name ContosoContext
    dotnet easyaf code generate all
    ```
  </Step>
  <Step title="Run the API">
    ```bash
    dotnet run --project CloudNimble.Contoso.Api
    ```
  </Step>
</Steps>
