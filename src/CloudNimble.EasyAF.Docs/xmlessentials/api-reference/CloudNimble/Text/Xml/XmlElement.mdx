## Summary

Represents a specific XML node within an [XmlDocument](/xmlessentials/api-reference/CloudNimble/Text/Xml/XmlDocument).

## Usage

An `XmlElement` is one node of an [`XmlDocument`](/xmlessentials/api-reference/CloudNimble/Text/Xml/XmlDocument): an element, an attribute, a text node, a CDATA section, a comment, or a processing instruction. `ValueKind` says which. It's the XML counterpart of `JsonElement`: a small struct that points into the document and is usable only while the document is alive.

You get the first one from `XmlDocument.RootElement`. From there, `GetChild` and `GetAttribute` find a node by name and throw an `XmlException` when it's missing, and `TryGetChild` and `TryGetAttribute` return `false` instead. The typed getters convert a value.

```csharp
const string xml = """
    <Order id="1042">
      <Customer>Ada Lovelace</Customer>
      <Total currency="GBP">129.90</Total>
    </Order>
    """;

using XmlDocument document = XmlDocument.Parse(xml);
XmlElement order = document.RootElement;

output.WriteLine($"Customer: {order.GetChild("Customer").GetString()}");
output.WriteLine($"Order id: {order.GetAttribute("id").GetInt32()}");

if (order.TryGetChild("Total", out XmlElement total) && total.TryGetAttribute("currency", out XmlElement currency))
{
    output.WriteLine($"Total: {total.GetDecimal()} {currency.GetString()}");
}

if (!order.TryGetChild("Discount", out _))
{
    output.WriteLine("No Discount element");
}

try
{
    order.GetChild("Discount");
}
catch (XmlException ex)
{
    output.WriteLine(ex.Message);
}

try
{
    order.GetAttribute("status");
}
catch (XmlException ex)
{
    output.WriteLine(ex.Message);
}
```

The code produces the following output:

```text
Customer: Ada Lovelace
Order id: 1042
Total: 129.90 GBP
No Discount element
Child element 'Discount' was not found.
Attribute 'status' was not found.
```

The members fall into these groups:

| To | Use |
| --- | --- |
| Identify the node | `ValueKind`, `TokenType`, `LocalName`, `Prefix`, `NamespaceUri`, `IsEmptyElement`, `IsNil` |
| Find a node by name | `GetChild`, `TryGetChild`, `GetAttribute`, `TryGetAttribute` |
| Visit every node | `EnumerateChildren`, `EnumerateAttributes`, `AttributeCount` |
| Read a value | `GetString`, `GetBoolean`, `GetInt32`, `GetInt64`, `GetDecimal`, `GetDouble`, `GetDateTime`, `GetDateTimeOffset`, `GetGuid`, `GetBytesFromBase64`, the other integer and floating-point getters, and a `TryGet` method for each typed getter except `GetBoolean` |
| Read text or markup | `GetInnerText`, `GetRawXml` |
| Write or copy the node | `WriteTo`, `CloneNode` |

## Remarks

This struct is the XML counterpart of `JsonElement` in System.Text.Json. A value can represent
an element, an attribute, a text node, a CDATA section, a comment, or a processing instruction;
[XmlElement.ValueKind](/xmlessentials/api-reference/CloudNimble/Text/Xml/XmlElement#valuekind) tells which. A value is usable only while its parent
[XmlDocument](/xmlessentials/api-reference/CloudNimble/Text/Xml/XmlDocument) is not disposed.
The value of an attribute, a text node, a CDATA section, a comment, or a processing instruction
is its content. The value of an element is the text of all text nodes and CDATA sections inside
it, in document order.
The typed getters, such as [XmlElement.GetInt32](/xmlessentials/api-reference/CloudNimble/Text/Xml/XmlElement#getint32), ignore leading and trailing white space in the value.
Name lookups, enumeration, the numeric and Boolean getters, and [XmlElement.WriteTo](/xmlessentials/api-reference/CloudNimble/Text/Xml/XmlElement#writeto) do not allocate.
Members that return a [String](https://learn.microsoft.com/dotnet/api/system.string), a `byte[]`, or an [XmlNode](/xmlessentials/api-reference/CloudNimble/Text/Xml/Nodes/XmlNode)
allocate only that result, except [XmlElement.GetRawXml](/xmlessentials/api-reference/CloudNimble/Text/Xml/XmlElement#getrawxml), which also allocates the buffer and the writer it writes the markup with.

## Examples

### Enumerate children and attributes

A document keeps the white space between elements and the comments, so a loop over the children skips what isn't an element.

```csharp
const string xml = """
    <Order id="1042" status="open">
      <Item sku="KB-1">Keyboard</Item>
      <Item sku="MS-2">Mouse</Item>
      <Note/>
    </Order>
    """;

using XmlDocument document = XmlDocument.Parse(xml);
XmlElement order = document.RootElement;

output.WriteLine($"{order.AttributeCount} attributes");
foreach (XmlElement attribute in order.EnumerateAttributes())
{
    output.WriteLine($"  {attribute.LocalName} = {attribute.GetString()}");
}

foreach (XmlElement child in order.EnumerateChildren())
{
    if (child.ValueKind is not (XmlValueKind.Element or XmlValueKind.EmptyElement or XmlValueKind.Nil))
    {
        continue;
    }

    if (child.TryGetAttribute("sku", out XmlElement sku))
    {
        output.WriteLine($"{child.LocalName} {sku.GetString()}: {child.GetString()}");
    }
    else
    {
        output.WriteLine($"{child.LocalName} ({child.ValueKind})");
    }
}
```

The code produces the following output:

```text
2 attributes
  id = 1042
  status = open
Item KB-1: Keyboard
Item MS-2: Mouse
Note (EmptyElement)
```

### Find names in a namespace

The one-argument lookups match a local name in any namespace. Pass a namespace URI to match one namespace, or an empty string for a name in no namespace.

```csharp
const string xml = """
    <feed xmlns="http://www.w3.org/2005/Atom" xmlns:dc="http://purl.org/dc/elements/1.1/">
      <title>Release notes</title>
      <dc:title>Notes de version</dc:title>
      <link href="https://example.com/" dc:language="fr"/>
    </feed>
    """;

const string atom = "http://www.w3.org/2005/Atom";
const string dc = "http://purl.org/dc/elements/1.1/";

using XmlDocument document = XmlDocument.Parse(xml);
XmlElement feed = document.RootElement;

output.WriteLine($"Atom title: {feed.GetChild("title", atom).GetString()}");
output.WriteLine($"Dublin Core title: {feed.GetChild("title", dc).GetString()}");
output.WriteLine($"First title in any namespace: {feed.GetChild("title").GetString()}");

XmlElement dcTitle = feed.GetChild("title", dc);
output.WriteLine($"Prefix '{dcTitle.Prefix}', local name '{dcTitle.LocalName}', namespace '{dcTitle.NamespaceUri}'");

XmlElement link = feed.GetChild("link", atom);
output.WriteLine($"href: {link.GetAttribute("href", "").GetString()}");
output.WriteLine($"language: {link.GetAttribute("language", dc).GetString()}");

output.WriteLine($"feed has {feed.AttributeCount} attributes:");
foreach (XmlElement attribute in feed.EnumerateAttributes())
{
    string name = attribute.Prefix.Length == 0 ? attribute.LocalName : $"{attribute.Prefix}:{attribute.LocalName}";
    output.WriteLine($"  {name} = {attribute.GetString()}");
}
```

The code produces the following output:

```text
Atom title: Release notes
Dublin Core title: Notes de version
First title in any namespace: Release notes
Prefix 'dc', local name 'title', namespace 'http://purl.org/dc/elements/1.1/'
href: https://example.com/
language: fr
feed has 2 attributes:
  xmlns = http://www.w3.org/2005/Atom
  xmlns:dc = http://purl.org/dc/elements/1.1/
```

### Read typed values

```csharp
const string xml = """
    <Shipment id="7c9e6679-7425-40de-944b-e07fc1f90ae7" express="1">
      <Parcels> 3 </Parcels>
      <WeightKg>12.5</WeightKg>
      <Cost>49.90</Cost>
      <TrackingNumber>940011189922</TrackingNumber>
      <ShippedOn>2026-03-14T09:30:00Z</ShippedOn>
      <Signature>SGVsbG8=</Signature>
      <Carrier>Contoso Freight</Carrier>
    </Shipment>
    """;

using XmlDocument document = XmlDocument.Parse(xml);
XmlElement shipment = document.RootElement;

Guid id = shipment.GetAttribute("id").GetGuid();
bool express = shipment.GetAttribute("express").GetBoolean();
int parcels = shipment.GetChild("Parcels").GetInt32();
double weight = shipment.GetChild("WeightKg").GetDouble();
decimal cost = shipment.GetChild("Cost").GetDecimal();
long tracking = shipment.GetChild("TrackingNumber").GetInt64();
DateTimeOffset shippedOn = shipment.GetChild("ShippedOn").GetDateTimeOffset();
byte[] signature = shipment.GetChild("Signature").GetBytesFromBase64();

output.WriteLine($"id: {id}");
output.WriteLine($"express: {express}");
output.WriteLine($"parcels: {parcels} (the string is '{shipment.GetChild("Parcels").GetString()}')");
output.WriteLine($"weight: {weight.ToString(CultureInfo.InvariantCulture)}");
output.WriteLine($"cost: {cost.ToString(CultureInfo.InvariantCulture)}");
output.WriteLine($"tracking: {tracking}");
output.WriteLine($"shipped on: {shippedOn.ToString("yyyy-MM-dd HH:mm zzz", CultureInfo.InvariantCulture)}");
output.WriteLine($"signature: {signature.Length} bytes");

try
{
    shipment.GetChild("Carrier").GetInt32();
}
catch (XmlException ex)
{
    output.WriteLine($"Carrier as an integer: {ex.Message}");
}
```

The code produces the following output:

```text
id: 7c9e6679-7425-40de-944b-e07fc1f90ae7
express: True
parcels: 3 (the string is ' 3 ')
weight: 12.5
cost: 49.90
tracking: 940011189922
shipped on: 2026-03-14 09:30 +00:00
signature: 5 bytes
Carrier as an integer: The value is not a valid integer.
```

### Compare GetString, GetInnerText, and GetRawXml

```csharp
const string xml = """<Note priority="high">Ship **today**, <![CDATA[before 5 & not later]]>.<?audit checked?></Note>""";

using XmlDocument document = XmlDocument.Parse(xml);
XmlElement note = document.RootElement;

output.WriteLine($"GetString:    {note.GetString()}");
output.WriteLine($"GetInnerText: {note.GetInnerText()}");
output.WriteLine($"GetRawXml:    {note.GetRawXml()}");

foreach (XmlElement child in note.EnumerateChildren())
{
    if (child.ValueKind is XmlValueKind.ProcessingInstruction)
    {
        output.WriteLine($"On the processing instruction, GetString is '{child.GetString()}' and GetInnerText is '{child.GetInnerText()}'");
    }
}

output.WriteLine($"GetRawXml on an attribute is empty: {note.GetAttribute("priority").GetRawXml().Length == 0}");
```

The code produces the following output:

```text
GetString:    Ship today, before 5 & not later.
GetInnerText: Ship today, before 5 & not later.
GetRawXml:    <Note priority="high">Ship **today**, <![CDATA[before 5 & not later]]>.<?audit checked?></Note>
On the processing instruction, GetString is 'checked' and GetInnerText is ''
GetRawXml on an attribute is empty: True
```

## Best Practices

- **Keep the document alive while you use its elements.** Don't return an `XmlElement` from a method that disposes the document or store one in a field that outlives it. Copy the value, or call `CloneNode`.
- **Test for all three element kinds.** An element's `ValueKind` is `Element`, `EmptyElement` (for `<e/>`), or `Nil`. A check for `Element` alone skips the other two.
- **Check `ValueKind` when you enumerate.** A document keeps comments and the white space between elements by default, so the children of an indented element include `Text` nodes for the indentation, as well as any CDATA sections, comments, and processing instructions.
- **Read values from leaf elements.** `GetString` and `GetInnerText` on an element that has child elements include the white space between them.
- **Use the `Try` lookups for optional names** and the `Get` lookups for names the document must have, so that a missing required name fails with a message that names it.
- **Pass the namespace URI when a document mixes vocabularies.** The one-argument lookups return the first match in any namespace.
- **Check `IsNil` before a typed getter** on an element that can carry `xsi:nil`. A typed getter on a nil element throws.
- **Use `GetDateTimeOffset` for values with a time zone.** `GetDateTime` converts an offset other than `Z` to local time.
- **Prefer a typed getter to parsing `GetString` yourself.** The getters apply the XML Schema lexical rules, don't depend on the current culture, and don't allocate a string.

## Patterns

### Switch on the kind of each child

Content you don't control can hold any kind of node. A `switch` on `ValueKind` handles each one.

```csharp
const string xml = """
    <Order xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"><!-- packed by hand --><Item>Keyboard</Item><Gift/><Coupon xsi:nil="true"/>Leave at the door<![CDATA[**fragile**]]><?print label?></Order>
    """;

using XmlDocument document = XmlDocument.Parse(xml);

foreach (XmlElement child in document.RootElement.EnumerateChildren())
{
    string description = child.ValueKind switch
    {
        XmlValueKind.Element or XmlValueKind.EmptyElement or XmlValueKind.Nil => $"<{child.LocalName}>",
        XmlValueKind.ProcessingInstruction => $"target '{child.LocalName}', data '{child.GetString()}'",
        _ => $"'{child.GetString()}'",
    };

    output.WriteLine($"{child.ValueKind,-21} {child.TokenType,-21} {description}");
}
```

The code produces the following output:

```text
Comment               Comment               ' packed by hand '
Element               StartElement          <Item>
EmptyElement          StartElement          <Gift>
Nil                   StartElement          <Coupon>
Text                  Text                  'Leave at the door'
CData                 CData                 '**fragile**'
ProcessingInstruction ProcessingInstruction target 'print', data 'label'
```

### Copy an element into the mutable tree

`CloneNode` returns a copy that owns its data and outlives the document.

```csharp
XmlElementNode product;

using (XmlDocument document = XmlDocument.Parse("""<Catalog><Product sku="KB-1"><Name>Keyboard</Name></Product></Catalog>"""))
{
    product = (XmlElementNode)document.RootElement.GetChild("Product").CloneNode();
}

product.SetAttribute("sku", "KB-2");
product.AddElement("Price").InnerText = "49.90";

output.WriteLine(product.ToString());
```

The code produces the following output:

```xml
<Product sku="KB-2"><Name>Keyboard</Name><Price>49.90</Price></Product>
```

### Write an element inside new markup

`WriteTo` writes the node and everything in it. The writer adds a declaration for any namespace that an ancestor outside the copied part declared.

```csharp
const string xml = """<c:Catalog xmlns:c="urn:example:catalog"><c:Product sku="KB-1">Keyboard</c:Product><c:Product sku="MS-2">Mouse</c:Product></c:Catalog>""";

using XmlDocument document = XmlDocument.Parse(xml);

var buffer = new ArrayBufferWriter<byte>();
var options = new XmlWriterOptions { Indented = true, NewLine = "\n", OmitXmlDeclaration = true };
using (var writer = new Utf8XmlWriter(buffer, options))
{
    writer.WriteStartElement("Picked");
    foreach (XmlElement product in document.RootElement.EnumerateChildren())
    {
        if (product.GetAttribute("sku").GetString() == "MS-2")
        {
            product.WriteTo(writer);
        }
    }

    writer.WriteEndElement();
}

output.WriteLine(Encoding.UTF8.GetString(buffer.WrittenSpan));
```

The code produces the following output:

```xml
<Picked>
  <c:Product xmlns:c="urn:example:catalog" sku="MS-2">Mouse</c:Product>
</Picked>
```

## Considerations

### Lifetime

- An `XmlElement` holds a reference to its document and a position in it. It holds no data of its own.
- After the document is disposed, every member that reads from it throws `ObjectDisposedException`.
- `default(XmlElement)` refers to no node. `ValueKind` returns `Undefined`, and every other member that reads a node throws `InvalidOperationException`.
- Two values are equal when they point at the same node of the same document.

### Values

- The value of an attribute, a text node, a CDATA section, a comment, or a processing instruction is its content. The value of an element is the text of every text node and CDATA section inside it, at any depth, in document order.
- The text of an element that has child elements includes the white space between them when the document keeps it, which is the default. For `<r>`, a line break, two spaces, ``x``, a line break, and `</r>`, the value of `r` is `"\n  x\n"` and the value of `c` is `"x"`.
- `GetString` returns the value unchanged, white space included, and `null` for a nil element. `GetInnerText` returns an empty string for a nil element, a comment, or a processing instruction.
- The typed getters ignore white space around the value and follow the XML Schema lexical forms. `GetBoolean` accepts `true`, `false`, `1`, and `0`. `GetDecimal` doesn't accept an exponent. `GetDouble` accepts `INF`, `-INF`, and `NaN`.
- A value that can't be converted throws `XmlException` from a getter and returns `false` from the `TryGet` method for the same type. A `TryGet` method still throws for a nil element and for a default `XmlElement`.
- The getters are those of `JsonElement`: `bool`, the eight integer types, `float`, `double`, `decimal`, `DateTime`, `DateTimeOffset`, `Guid`, and Base64 bytes. For another type, convert the result of `GetString`.
- `GetDateTime` returns `DateTimeKind.Utc` for a value that ends in `Z`, `Unspecified` for a value without a time zone, and local time for any other offset. `GetDateTimeOffset` gives a value without a time zone the local offset.

### Navigation

- `GetChild` and `TryGetChild` search direct children and return the first match in document order. To search deeper, chain the calls or write a recursive method over `EnumerateChildren`. To reach a parent or a sibling, keep it in your own loop, or use the mutable tree, whose nodes have a `Parent`.
- `GetChild`, `TryGetChild`, and `GetAttribute` have an overload that takes a namespace URI. `TryGetAttribute` matches the local name in any namespace.
- `EnumerateChildren` returns every child node. With the default options that includes a `Text` node for each run of white space between elements and a `Comment` node for each comment.
- `AttributeCount` and `EnumerateAttributes` include namespace declarations (`xmlns` and `xmlns:prefix`).
- The enumerators are structs that work with `foreach`. They don't implement `IEnumerable<T>`, so LINQ doesn't apply.
- On a node that isn't an element, the lookups find nothing, the enumerators are empty, and `LocalName` is an empty string (or the target, for a processing instruction).

### Allocation

Name lookups, enumeration, the numeric, Boolean, date, and GUID getters, and `WriteTo` don't allocate. `LocalName`, `Prefix`, `NamespaceUri`, `GetString`, and `GetInnerText` allocate the string they return, `GetBytesFromBase64` allocates the array, and `CloneNode` allocates the copy. `GetRawXml` writes the node with a `Utf8XmlWriter` into a buffer of its own and returns the result as a string.

### Markup

`GetRawXml` writes the node with a `Utf8XmlWriter`; it isn't a slice of the original input. It takes no options, so its line ends are line feeds on every operating system. It returns an empty string for an attribute. `IsEmptyElement` is `true` for `<e/>` and `false` for `<e></e>`, and `WriteTo` keeps the difference.
