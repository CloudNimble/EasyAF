## Summary

Specifies that a member holds the mixed content of the element for its containing type: text interleaved with child elements. This class cannot be inherited.

## Usage

Put `[XmlMixed]` on a `List<XmlMixedContentItem>` member to map an element whose content is text with child elements inside it. The serializer fills the list with `XmlMixedText` and `XmlMixedElement` items in document order, and writes them back in the order of the list.

```csharp
public sealed class Paragraph
{
    [XmlMixed]
    public List<XmlMixedContentItem> Content { get; set; } = [];
}
```

Deserializing `<Paragraph>Press <Key>Ctrl</Key> and <Key>S</Key> to save.</Paragraph>` into this type gives five items: the text `Press `, a `Key` element, the text ` and `, a second `Key` element, and the text ` to save.`

See [Mixed content and overflow](/xmlessentials/guides/mixed-content) for the complete example, and the [mixed content sample](https://github.com/CloudNimble/XmlEssentials/blob/main/src/CloudNimble.XmlEssentials.Samples/18_MixedContent.cs).

## Remarks

The member is a collection of [XmlMixedContentItem](/xmlessentials/api-reference/CloudNimble/Text/Xml/Serialization/XmlMixedContentItem). A type can have one member with this attribute, and
that type cannot also map members to child elements or to text content.

## Considerations

- A type can have one `[XmlMixed]` member. It can also have members mapped to attributes. It can't have members mapped to child elements, or an `[XmlText]` or `[XmlCData]` member. The serializer throws `NotSupportedException` for those combinations when it builds the type's metadata.
- Every child element goes into the list as an `XmlMixedElement`. Child elements aren't deserialized into typed objects.
- Text that is only white space between two elements is dropped unless `XmlSerializerOptions.WhitespaceHandling` is `XmlWhitespaceHandling.Significant`.
- A CDATA section is read as text and written back as escaped text. Comments and processing instructions are not kept.
- Each element is held as a mutable `XmlElementNode`, which allocates a node for the element and for each of its descendants. For large documents that are mostly mixed content, consider reading with `Utf8XmlReader` or `XmlDocument` instead.
