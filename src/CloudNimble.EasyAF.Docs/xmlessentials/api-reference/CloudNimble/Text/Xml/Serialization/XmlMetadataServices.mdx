## Summary

Provides helpers to create and use metadata for XML-serializable types. This class cannot be inherited.

## Usage

`XmlMetadataServices` is infrastructure for source-generated code. The code that the XmlEssentials generator writes into your `XmlSerializerContext` classes calls these methods to create type info from generated metadata, to write members through type info in the write fast path, and to write the start and end tags of simple elements from bytes prepared at compile time.

`CreateObjectInfo` turns an `XmlObjectInfoValues<T>` into type info. The serializer then reads and writes the type from that metadata with the engine the reflection resolver uses, and with no reflection over the members of the type. `CanUseSerializeHandler` tells a context whether its write fast path agrees with a given options instance.

The class isn't meant to be called from application code. Its methods are public because generated code lives in your assembly and has to reach them, and most of them are hidden from IntelliSense. `WriteLeafStart` and `WriteLeafEnd` write a tag as raw bytes and rely on the generator to pass a well-formed one. A resolver you write by hand can call `CreateObjectInfo` and the other `Create` methods, as a generated context does.

To do the same things in application code, use the public entry points instead:

| Instead of | Use |
| --- | --- |
| `CreateObjectInfo`, `CreateValueInfo` | A context's `XmlTypeInfo<T>` property, or `XmlSerializerOptions.GetTypeInfo<T>()`. |
| `Read`, `ReadAttribute` | `XmlSerializer.Deserialize` with type info, or `Utf8XmlReader` directly. |
| `Write`, `WriteAttribute` | `XmlSerializer.Serialize` with type info, or `Utf8XmlWriter` directly. |
| `WriteLeafStart`, `WriteLeafEnd` | `Utf8XmlWriter.WriteStartElement` and `WriteEndElement`. |

The class is the counterpart of `JsonMetadataServices` in System.Text.Json. To see how generated code is produced and used, see [How to use source generation](/xmlessentials/guides/source-generation).

## Remarks

Source-generated contexts call these methods. This class is analogous to `JsonMetadataServices` in `System.Text.Json`.

Returns whether the write fast path a context generated can be used with the given options.

#### Syntax

public static bool CanUseSerializeHandler(CloudNimble.Text.Xml.XmlSerializerOptions options, CloudNimble.Text.Xml.XmlNamingPolicy elementNamingPolicy, CloudNimble.Text.Xml.XmlNamingPolicy attributeNamingPolicy, CloudNimble.Text.Xml.XmlPropertyMapping defaultPropertyMapping, CloudNimble.Text.Xml.XmlCollectionMapping defaultCollectionMapping, bool includeFields, params System.ReadOnlySpan<System.Type> directTypes)
```

#### Parameters

| Name | Type | Description |
|------|------|-------------|
| `options` | `CloudNimble.Text.Xml.XmlSerializerOptions` | The options the type info is for. |
| `elementNamingPolicy` | `CloudNimble.Text.Xml.XmlNamingPolicy?` | The policy the element names were generated with, or [`null`](https://learn.microsoft.com/dotnet/csharp/language-reference/keywords/null) for none. |
| `attributeNamingPolicy` | `CloudNimble.Text.Xml.XmlNamingPolicy?` | The policy the attribute names were generated with, or [`null`](https://learn.microsoft.com/dotnet/csharp/language-reference/keywords/null) for none. |
| `defaultPropertyMapping` | `CloudNimble.Text.Xml.XmlPropertyMapping` | The property mapping the members were generated with. |
| `defaultCollectionMapping` | `CloudNimble.Text.Xml.XmlCollectionMapping` | The collection mapping the members were generated with. |
| `includeFields` | `bool` | Whether the fast path was generated with fields included. |
| `directTypes` | `System.ReadOnlySpan<System.Type>` | The types the fast path writes without a converter, the type itself first. |

#### Returns

Type: `bool`
[`true`](https://learn.microsoft.com/dotnet/csharp/language-reference/builtin-types/bool) when the fast path writes what the serializer would write from the metadata with
these options; otherwise, [`false`](https://learn.microsoft.com/dotnet/csharp/language-reference/builtin-types/bool).

#### Exceptions

| Exception | Description |
|-----------|-------------|
| `ArgumentNullException` | *options* is [`null`](https://learn.microsoft.com/dotnet/csharp/language-reference/keywords/null). |

#### Remarks

The fast path has its element and attribute names and its choice of members compiled in, from
[XmlSourceGenerationOptionsAttribute](/xmlessentials/api-reference/CloudNimble/Text/Xml/Serialization/XmlSourceGenerationOptionsAttribute). It is not used when the options ask for another naming
policy, property mapping, collection mapping or choice of members, when they handle references, when they
write a [`null`](https://learn.microsoft.com/dotnet/csharp/language-reference/keywords/null), a [Char](https://learn.microsoft.com/dotnet/api/system.char) or a zero offset another way, when they put fields first, or when they supply a converter
for a type it writes directly. The serializer then writes from the metadata, which follows every option.
This method is for source-generated contexts only.

### <Icon icon="thumbtack" iconType="duotone" color="#419AC5" size={24} className="mr-2" /> WriteCData

```

#### Parameters

#### Exceptions

| Exception | Description |
|-----------|-------------|
| `ArgumentNullException` | *writer* is [`null`](https://learn.microsoft.com/dotnet/csharp/language-reference/keywords/null). |
| `XmlException` | *text* holds a character that XML does not allow. |

#### Remarks

A CDATA section ends at the first `]]>`, so text that holds one is cut between the brackets and the angle
bracket and written as adjacent sections, which read back as one value. This method is for the write fast path of a
source-generated context only.
