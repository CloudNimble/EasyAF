## Summary

Indicates that the annotated member must be present in the XML on deserialization. This class cannot be inherited.

## Usage

Apply `[XmlRequired]` to a property or field that must be present in the XML when deserializing. It is the counterpart of `[JsonRequired]`, and it has the same effect as the C# `required` modifier without making the compiler demand the member in object initializers.

```csharp
public sealed class Registration
{
    public required string Email { get; set; }

    [XmlRequired]
    public string? Plan { get; set; }

    public string? Referrer { get; set; }
}
```

```csharp
string[] documents =
[
    "<Registration><Email>ada@contoso.example</Email><Plan>pro</Plan></Registration>",
    "<Registration><Plan>pro</Plan></Registration>",
    "<Registration><Email>ada@contoso.example</Email></Registration>",
];

foreach (string xml in documents)
{
    try
    {
        Registration? registration = XmlSerializer.Deserialize<Registration>(xml);
        output.WriteLine($"{registration!.Email} chose {registration.Plan}");
    }
    catch (XmlException ex)
    {
        output.WriteLine(ex.Message);
    }
}
```

The code produces the following output:

```text
ada@contoso.example chose pro
The required member 'Email' is missing. Path: /Registration | LineNumber: 1 | BytePositionInLine: 46.
The required member 'Plan' is missing. Path: /Registration | LineNumber: 1 | BytePositionInLine: 64.
```

[View the complete sample on GitHub](https://github.com/CloudNimble/XmlEssentials/blob/main/src/CloudNimble.XmlEssentials.Samples/10_RequiredProperties.cs)

## Remarks

This attribute is analogous to `JsonRequiredAttribute` in `System.Text.Json`.

## Considerations

- A missing required member throws an [`XmlException`](/xmlessentials/api-reference/CloudNimble/Text/Xml/XmlException) whose message names the member by its XML name.
- A required element that is present but marked `xsi:nil="true"` is also rejected, with the message `The required member 'Email' cannot be nil.`
- An empty element satisfies the requirement. For a `string` member, the value is the empty string. The attribute checks presence, not content.
- The attribute affects reading only. A required member whose value is `null` is still written as nil, or left out, by the usual rules.
- A required collection that is written as repeated elements counts as present when the XML has at least one item.
- Constructor parameters with no default value are required without the attribute. See [Constructor parameters](/xmlessentials/guides/required-properties#constructor-parameters).
