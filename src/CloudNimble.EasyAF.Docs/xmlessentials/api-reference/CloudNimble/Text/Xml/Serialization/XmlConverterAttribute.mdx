## Summary

Specifies the converter type to use when placed on a property, field, or type. This class cannot be inherited.

## Usage

Apply `[XmlConverter]` to a class, struct, or enumeration to name the converter the serializer uses for it. Every `XmlSerializerOptions` instance then uses that converter, with nothing to register. Apply it to a property or field instead to convert that one member.

```csharp
[XmlConverter<GeoPointConverter>]
public readonly struct GeoPoint
{
    public GeoPoint(double latitude, double longitude)
    {
        Latitude = latitude;
        Longitude = longitude;
    }

    public double Latitude { get; }

    public double Longitude { get; }
}
```

```csharp
var options = new XmlSerializerOptions { OmitXmlDeclaration = true };
var warehouse = new Warehouse { Name = "North", Location = new GeoPoint(47.61, -122.33) };

string xml = XmlSerializer.Serialize(warehouse, options);
output.WriteLine(xml);

Warehouse? copy = XmlSerializer.Deserialize<Warehouse>(xml, options);
output.WriteLine($"{copy!.Name}: {copy.Location.Latitude}, {copy.Location.Longitude}");
```

The code produces the following output:

```text
<Warehouse><Location><Lat>47.61</Lat><Lon>-122.33</Lon></Location><Name>North</Name></Warehouse>
North: 47.61, -122.33
```

The converter type must derive from `XmlConverter<T>` or `XmlConverterFactory` and have a public parameterless constructor. The attribute is the counterpart of `JsonConverterAttribute` in System.Text.Json.

[View the complete sample on GitHub](https://github.com/CloudNimble/XmlEssentials/blob/main/src/CloudNimble.XmlEssentials.Samples/35_CustomConverters.cs)

## Remarks

On a type, the converter reads and writes every value of the type, unless [XmlSerializerOptions.Converters](/xmlessentials/api-reference/CloudNimble/Text/Xml/XmlSerializerOptions#converters)
holds a converter for it. On a property or field, the converter reads and writes that member only, and comes before
both. It handles the whole value of the member: a collection is not taken apart into items, the member may be an
attribute or text, and a converter for `T` serves a member of type `T?`. A source-generated context applies
the attribute on a type and on a member, as the reflection resolver does. The converter is a type argument, so the
compiler checks that it is a converter and can be created, and no reflection is needed to create it.

## Type Parameters

- `TConverter` - The type of the converter. It derives from [XmlConverter](/xmlessentials/api-reference/CloudNimble/Text/Xml/Serialization/XmlConverter) and has a public parameterless constructor.

## Examples

```csharp
[XmlConverter<MoneyConverter>]
public readonly record struct Money(decimal Amount, string Currency);
```

## Considerations

- **On a property or field, the converter serves that member only.** It reads and writes the whole value of the member, as `[JsonConverter]` does in System.Text.Json: a collection isn't taken apart into items, the member may be an attribute or text, and a converter for `T` serves a member of type `T?`. A member attribute comes before `XmlSerializerOptions.Converters` and before an attribute on the type.
- **A converter in the options wins over the attribute on a type.** `XmlSerializerOptions.Converters` is searched before the attribute on the type, so a caller can override the converter a type names. It doesn't override an attribute on a member.
- **One instance for each options instance.** The serializer creates the converter the first time the options need it and keeps it. A converter named on a property or field is created once for that member.
- **The converter is a type argument.** `[XmlConverter<MoneyConverter>]` names the converter, and the compiler checks that it derives from `XmlConverter` and has a public parameterless constructor. A converter that can't convert the annotated type still fails at run time: the serializer throws `InvalidOperationException` when it first needs it.
- **Source generation reads the attribute on a type and on a member.** A generated context reads and writes a type that carries `[XmlConverter]` with that converter, in place of generated metadata for the type. On a property or field, the attribute is carried in the generated metadata, and the converter reads and writes that member.
- **The converter is created without reflection.** The converter type is a type argument with a `new()` constraint, so the attribute creates it directly and trimming and Native AOT need nothing extra.
