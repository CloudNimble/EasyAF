## Summary

Determines how a member that already holds a value is handled when it is deserialized. This class cannot be inherited.

## Usage

Apply `[XmlObjectCreationHandling]` to a property or field to say whether the value it already holds is replaced or populated when it is read. The attribute takes precedence over `XmlSerializerOptions.PreferredObjectCreationHandling` for that member. It is the counterpart of `[JsonObjectCreationHandling]`.

```csharp
public sealed class Playlist
{
    // The items are added to the list the property already holds.
    [XmlObjectCreationHandling(XmlObjectCreationHandling.Populate)]
    public List<string> Tracks { get; } = [];
}
```

Apply it to a type to set the handling for every member of the type that can be populated.

`Populate` on a member that can't be populated throws an `InvalidOperationException` the first time the type is used. That covers an array, an immutable or frozen collection, a collection declared as a read-only interface such as `IEnumerable<T>`, a single value such as a `string` or a number, a value with a custom converter, mixed content, a polymorphic type, and a value type with no setter. On a type that is created through a constructor with parameters, or on a member of such a type, it throws a `NotSupportedException`.

See [Populate a collection that already holds a value](/xmlessentials/guides/collections#populate-a-collection-that-already-holds-a-value).

## Remarks

On a property or field, the attribute takes precedence over
[XmlSerializerOptions.PreferredObjectCreationHandling](/xmlessentials/api-reference/CloudNimble/Text/Xml/XmlSerializerOptions#preferredobjectcreationhandling) for that member. On a type, it applies to
every member of the type that can be populated.

[XmlObjectCreationHandling.Populate](/xmlessentials/api-reference/CloudNimble/Text/Xml/Serialization/XmlObjectCreationHandling) on a member that cannot be populated throws an
          [InvalidOperationException](https://learn.microsoft.com/dotnet/api/system.invalidoperationexception) when the type is first used: an array, an immutable collection, a
          value with a custom converter, a polymorphic type, or a value type with no setter. On a type that is created
          through a constructor with parameters it throws a [NotSupportedException](https://learn.microsoft.com/dotnet/api/system.notsupportedexception).

## Examples

```csharp
public sealed class Playlist
{
    [XmlObjectCreationHandling(XmlObjectCreationHandling.Populate)]
    public List<string> Tracks { get; } = [];
}
```
