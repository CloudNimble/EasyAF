## Summary

Specifies the name and namespace of the document element that a type is serialized as. This class cannot be inherited.

## Usage

Apply `[XmlRoot]` to a class, struct, or interface to name the document element that is written when a value of that type is the root of the document. Without it, the document element is the type name, converted by the element naming policy.

```csharp
[XmlRoot("product")]
public sealed class CatalogItem
{
    [XmlAttribute("sku")]
    public string? Sku { get; set; }

    [XmlPropertyName("title")]
    public string? Name { get; set; }

    [XmlElement("unit-price")]
    public decimal UnitPrice { get; set; }
}
```

```csharp
var item = new CatalogItem { Sku = "KB-101", Name = "Keyboard", UnitPrice = 49.95m };
var options = new XmlSerializerOptions { OmitXmlDeclaration = true };

string xml = XmlSerializer.Serialize(item, options);
output.WriteLine(xml);

CatalogItem? copy = XmlSerializer.Deserialize<CatalogItem>(xml, options);
output.WriteLine($"{copy!.Sku}: {copy.Name}");
```

The code produces the following output:

```text
<product sku="KB-101"><title>Keyboard</title><unit-price>49.95</unit-price></product>
KB-101: Keyboard
```

[View the complete sample on GitHub](https://github.com/CloudNimble/XmlEssentials/blob/main/src/CloudNimble.XmlEssentials.Samples/08_CustomizeNames.cs)

Set `Namespace` to put the document element in an XML namespace. See [Namespaces](/xmlessentials/guides/namespaces).

## Considerations

- The name is used exactly as written. A naming policy doesn't convert it.
- When reading, the document element must have this name, or the serializer throws an `XmlException`. The name is matched with case unless `PropertyNameCaseInsensitive` is set, which ignores the case of ASCII letters for the document element as it does for members.
- The attribute names the type as a document element. When the type is the type of a member of another object, the element is named after that member.
- When `Namespace` is `null`, `XmlSerializerOptions.DefaultNamespace` is used.
- A `null` reference at the root is always written as the document element marked `xsi:nil="true"`.
