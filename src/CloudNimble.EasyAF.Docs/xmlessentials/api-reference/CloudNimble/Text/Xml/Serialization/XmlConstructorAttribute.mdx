## Summary

Indicates that the constructor is used to create instances of the type on deserialization. This class cannot be inherited.

## Usage

Apply `[XmlConstructor]` to the constructor that the serializer should call when it deserializes the type. It is the counterpart of `[JsonConstructor]`. You need it when a type has more than one constructor that could be used, or when the constructor isn't public.

```csharp
public sealed class DateRange
{
    public DateOnly Start { get; }

    public DateOnly End { get; }

    public DateRange(DateOnly start, int days)
        : this(start, start.AddDays(days - 1))
    {
    }

    [XmlConstructor]
    public DateRange(DateOnly start, DateOnly end)
    {
        Start = start;
        End = end;
    }
}
```

```csharp
var options = new XmlSerializerOptions { OmitXmlDeclaration = true };
var week = new DateRange(new DateOnly(2026, 3, 9), days: 7);

string xml = XmlSerializer.Serialize(week, options);
output.WriteLine(xml);

DateRange? copy = XmlSerializer.Deserialize<DateRange>(xml, options);
output.WriteLine($"{copy!.Start:yyyy-MM-dd} to {copy.End:yyyy-MM-dd}");
```

The code produces the following output:

```text
<DateRange><Start>2026-03-09</Start><End>2026-03-15</End></DateRange>
2026-03-09 to 2026-03-15
```

[View the complete sample on GitHub](https://github.com/CloudNimble/XmlEssentials/blob/main/src/CloudNimble.XmlEssentials.Samples/11_ImmutableTypes.cs)

The serializer reads the whole element, then calls the constructor with the values it found. Members that aren't constructor parameters are set afterward.

## Considerations

- **Parameter names are matched without regard to case,** as in System.Text.Json. Each parameter must have the C# name or the XML name of a serialized member, so a camelCase parameter such as `start` fills a property named `Start`. A member spelled exactly like the parameter is preferred, so two members that differ only by case each take their own parameter. `PropertyNameCaseInsensitive` has no part in this: it decides only how names in the document match members.
- A parameter that matches no member, and has no default value, makes the serializer throw a `NotSupportedException` the first time the type is used. That includes serializing the type.
- Only one constructor of a type can be marked. Marking two throws a `NotSupportedException`.
- A parameter with no default value is required: XML that lacks it is rejected with an `XmlException`, unless `RespectRequiredConstructorParameters` is `false`.
- Without the attribute, the serializer uses the public parameterless constructor, and a struct is created as its default value. A class with no public parameterless constructor is created through its one public constructor with parameters; with more than one, the serializer throws a `NotSupportedException` that asks you to mark one. These are the rules of System.Text.Json. A positional record needs no attribute, because its one public constructor has parameters with the same names as its properties.
- Don't combine constructor-set, get-only properties with `IgnoreReadOnlyProperties`. The option removes those properties from the mapping.
