## Summary

Specifies that a collection member is serialized as a wrapper element that contains the items. This class cannot be inherited.

## Usage

Apply `[XmlArray]` to a collection property or field to write its items inside one wrapper element. Without the attribute, the items are written as repeated elements named after the member, with no wrapper. Pair it with [`[XmlArrayItem]`](/api-reference/CloudNimble/Text/Xml/Serialization/XmlArrayItemAttribute) to name the items.

```csharp
public sealed class Album
{
    public string? Title { get; set; }

    [XmlArray("Tracks")]
    [XmlArrayItem("Track")]
    public List<string>? Tracks { get; set; }
}
```

```csharp
var album = new Album { Title = "Kind of Blue", Tracks = ["So What", "Freddie Freeloader"] };
var options = new XmlSerializerOptions { WriteIndented = true, NewLine = "\n", OmitXmlDeclaration = true };

string xml = XmlSerializer.Serialize(album, options);
output.WriteLine(xml);
```

The code produces the following output:

```xml
<Album>
  <Title>Kind of Blue</Title>
  <Tracks>
    <Track>So What</Track>
    <Track>Freddie Freeloader</Track>
  </Tracks>
</Album>
```

[View the complete sample on GitHub](https://github.com/CloudNimble/XmlEssentials/blob/main/src/CloudNimble.XmlEssentials.Samples/12_SerializeCollections.cs)

The name is optional. `[XmlArray]` with no arguments uses the member name for the wrapper.

## Remarks

Without this attribute, the items are written as repeated elements that use the member's element name, with no wrapper.

## Examples

The following examples show the names and the shapes that a wrapped collection produces.

### Default item names

Without `[XmlArrayItem]`, each item of a wrapped collection is named after its type. A built-in type has its XML Schema name, so an `int` item is `<int>`.

```csharp
public sealed class Scoreboard
{
    public string? Player { get; set; }

    [XmlArray]
    public int[]? Scores { get; set; }
}
```

```csharp
var board = new Scoreboard { Player = "Ada", Scores = [90, 85] };
var options = new XmlSerializerOptions { OmitXmlDeclaration = true };

output.WriteLine(XmlSerializer.Serialize(board, options));
```

The code produces the following output:

```xml
<Scoreboard><Player>Ada</Player><Scores><int>90</int><int>85</int></Scores></Scoreboard>
```

### Empty and null collections

A wrapper can show the difference between an empty collection and a `null` one. Repeated elements with no wrapper can't. `Playlist.Tracks` in the following example has no `[XmlArray]`.

```csharp
var options = new XmlSerializerOptions { OmitXmlDeclaration = true };

output.WriteLine(XmlSerializer.Serialize(new Playlist { Name = "Empty", Tracks = [] }, options));
output.WriteLine(XmlSerializer.Serialize(new Album { Title = "Empty", Tracks = [] }, options));
output.WriteLine(XmlSerializer.Serialize(new Album { Title = "Null", Tracks = null }, options));

Album? empty = XmlSerializer.Deserialize<Album>("<Album><Title>Empty</Title><Tracks /></Album>");
output.WriteLine($"Wrapped and empty: {empty!.Tracks?.Count.ToString() ?? "null"}");

Album? missing = XmlSerializer.Deserialize<Album>("<Album><Title>Missing</Title></Album>");
output.WriteLine($"Wrapper missing: {missing!.Tracks?.Count.ToString() ?? "null"}");
```

The code produces the following output:

```text
<Playlist><Name>Empty</Name></Playlist>
<Album><Title>Empty</Title><Tracks/></Album>
<Album><Title>Null</Title><Tracks xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance" xsi:nil="true"/></Album>
Wrapped and empty: 0
Wrapper missing: null
```

[View the complete sample on GitHub](https://github.com/CloudNimble/XmlEssentials/blob/main/src/CloudNimble.XmlEssentials.Samples/12_SerializeCollections.cs)

## Considerations

- `System.Xml.Serialization.XmlSerializer` wraps collections by default. This serializer doesn't, so add `[XmlArray]` when you need XML that matches what that serializer produced, or set `XmlSerializerOptions.DefaultCollectionMapping` to `XmlCollectionMapping.Wrapped` to wrap every collection member that has no mapping attribute.
- The default item name is the one `System.Xml.Serialization` uses: the XML Schema name of a built-in type, such as `int`, `string`, `boolean`, or `dateTime`, and the name of the type otherwise, such as the name of your class. A name that comes from the type, not from `[XmlRoot]`, is converted by the element naming policy.
- `[XmlPropertyName]` on the same member takes precedence over `ElementName`, and `[XmlPropertyOrder]` and `[XmlElement(Order = n)]` take precedence over `Order`.
- A `null` wrapped collection is written as the wrapper marked `xsi:nil="true"`. It is left out when the ignore condition that applies to the member is `WhenWritingNull`, `WhenWritingNullReference`, or `WhenWritingDefault`.
- The attribute applies to collections. A dictionary is always written inside an element named after the member, without it.

[XmlElementAttribute.Order](/xmlessentials/api-reference/CloudNimble/Text/Xml/Serialization/XmlElementAttribute#order) on the same member sets an order.
