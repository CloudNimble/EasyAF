## Summary

Provides serialization metadata about a property or field. This class cannot be inherited.

## Remarks

Source-generated contexts create instances of this class. It is analogous to
`JsonPropertyInfoValues<T>` in `System.Text.Json`. The names, the ignore conditions and the
mapping of the member are not given here: the serializer works them out from [XmlPropertyInfoValues`1.Attributes](/xmlessentials/api-reference/CloudNimble/Text/Xml/Serialization/XmlPropertyInfoValues#attributes) and the
options, exactly as it does for a member it finds through reflection.

## Type Parameters

- `TValue` - The type of the property or field.
