## Summary

Represents a run of text in mixed content. This class cannot be inherited.

## Usage

An `XmlMixedText` is a run of text inside mixed content. Its `Text` property holds the characters after entity and character references have been resolved, so `&lt;` in the document is `<` in the property.

The serializer creates one item for each run of text between child elements. To add text yourself, create an item and add it to the list:

```csharp
paragraph.Content.Add(new XmlMixedText(" "));
```

When the list is written, the text is escaped as needed. See `XmlMixedContentItem` for an example that reads text runs.

## Considerations

- White space inside a run is kept exactly, including the spaces next to a child element. A run that is only white space is dropped when reading unless `XmlSerializerOptions.WhitespaceHandling` is `XmlWhitespaceHandling.Significant`.
- A CDATA section is read as an `XmlMixedText`. It is written back as escaped text, not as CDATA.
- `Text` is never `null` on an item the serializer creates, and its default is the empty string.
