## Summary

Specifies compile-time source generator configuration when applied to [XmlSerializerContext](/api-reference/CloudNimble/Text/Xml/Serialization/XmlSerializerContext) class declarations.
This class cannot be inherited.

## Usage

Apply `[XmlSourceGenerationOptions]` to a source-generated context to set the options its `Default` instance uses and the mode the generator works in.

```csharp
[XmlSourceGenerationOptions(
    OmitXmlDeclaration = true,
    PropertyNamingPolicy = XmlKnownNamingPolicy.CamelCase)]
[XmlSerializable<Order>]
public partial class CamelCaseOrderXmlContext : XmlSerializerContext
{
}
```

```csharp
string xml = XmlSerializer.Serialize(CreateOrder(), CamelCaseOrderXmlContext.Default.Order);
output.WriteLine(xml);
```

The code produces the following output:

```xml
<order id="1042"><customer>Ada</customer><Line><quantity>1</quantity><sku>KB-01</sku></Line><Line><quantity>2</quantity><sku>MS-02</sku></Line></order>
```

The attribute seeds the options of `Default` and of a context created with the parameterless constructor. A context created with `new CamelCaseOrderXmlContext(options)` uses the options you pass instead.

The attribute is the counterpart of `JsonSourceGenerationOptionsAttribute` in System.Text.Json. An attribute argument must be a constant, so naming policies are chosen with the `XmlKnownNamingPolicy` enumeration and not with an `XmlNamingPolicy` instance.

[View the complete sample on GitHub](https://github.com/CloudNimble/XmlEssentials/blob/main/src/CloudNimble.XmlEssentials.Samples/32_UseSourceGeneration.cs)

## Remarks

The values are the default options of the generated context. They apply when the context is created without options.
When the caller passes an [XmlSerializerOptions](/xmlessentials/api-reference/CloudNimble/Text/Xml/XmlSerializerOptions) instance to the constructor, as in
`new AppXmlContext(options)`, that instance is used as it is and takes precedence over this attribute.

The source generator reads [XmlSourceGenerationOptionsAttribute.AttributeNamingPolicy](/xmlessentials/api-reference/CloudNimble/Text/Xml/Serialization/XmlSourceGenerationOptionsAttribute#attributenamingpolicy), [XmlSourceGenerationOptionsAttribute.DefaultIgnoreCondition](/xmlessentials/api-reference/CloudNimble/Text/Xml/Serialization/XmlSourceGenerationOptionsAttribute#defaultignorecondition),
[XmlSourceGenerationOptionsAttribute.DefaultNamespace](/xmlessentials/api-reference/CloudNimble/Text/Xml/Serialization/XmlSourceGenerationOptionsAttribute#defaultnamespace), [XmlSourceGenerationOptionsAttribute.DefaultPropertyMapping](/xmlessentials/api-reference/CloudNimble/Text/Xml/Serialization/XmlSourceGenerationOptionsAttribute#defaultpropertymapping), [XmlSourceGenerationOptionsAttribute.ElementNamingPolicy](/xmlessentials/api-reference/CloudNimble/Text/Xml/Serialization/XmlSourceGenerationOptionsAttribute#elementnamingpolicy),
[XmlSourceGenerationOptionsAttribute.GenerationMode](/xmlessentials/api-reference/CloudNimble/Text/Xml/Serialization/XmlSourceGenerationOptionsAttribute#generationmode), [XmlSourceGenerationOptionsAttribute.IncludeFields](/xmlessentials/api-reference/CloudNimble/Text/Xml/Serialization/XmlSourceGenerationOptionsAttribute#includefields),
[XmlSourceGenerationOptionsAttribute.OmitXmlDeclaration](/xmlessentials/api-reference/CloudNimble/Text/Xml/Serialization/XmlSourceGenerationOptionsAttribute#omitxmldeclaration), [XmlSourceGenerationOptionsAttribute.PreferredObjectCreationHandling](/xmlessentials/api-reference/CloudNimble/Text/Xml/Serialization/XmlSourceGenerationOptionsAttribute#preferredobjectcreationhandling), [XmlSourceGenerationOptionsAttribute.PropertyNamingPolicy](/xmlessentials/api-reference/CloudNimble/Text/Xml/Serialization/XmlSourceGenerationOptionsAttribute#propertynamingpolicy),
[XmlSourceGenerationOptionsAttribute.RespectNullableAnnotations](/xmlessentials/api-reference/CloudNimble/Text/Xml/Serialization/XmlSourceGenerationOptionsAttribute#respectnullableannotations), [XmlSourceGenerationOptionsAttribute.UnknownTypeHandling](/xmlessentials/api-reference/CloudNimble/Text/Xml/Serialization/XmlSourceGenerationOptionsAttribute#unknowntypehandling), and [XmlSourceGenerationOptionsAttribute.WriteIndented](/xmlessentials/api-reference/CloudNimble/Text/Xml/Serialization/XmlSourceGenerationOptionsAttribute#writeindented).
It does not read the other properties.

This attribute is analogous to `JsonSourceGenerationOptionsAttribute` in `System.Text.Json`.

## Considerations

- **The generator acts on every property.** `GenerationMode` chooses what is generated. Every other property is copied to the options of `Default`: `WriteIndented`, `OmitXmlDeclaration`, `EmitByteOrderMark`, `XmlVersion`, `DefaultNamespace`, `PropertyNamingPolicy`, `ElementNamingPolicy`, `AttributeNamingPolicy`, `PropertyNameCaseInsensitive`, `IncludeFields`, `IgnoreReadOnlyFields`, `IgnoreReadOnlyProperties`, `DefaultIgnoreCondition`, `DefaultPropertyMapping`, `DefaultCollectionMapping`, `MemberOrder`, `EnumHandling`, `CharHandling`, `UtcOffsetHandling`, `MaxDepth`, `PreferredObjectCreationHandling`, `RespectNullableAnnotations`, and `UnknownTypeHandling`.
- **`IgnoreReadOnlyFields` and `IgnoreReadOnlyProperties` turn the write fast path off.** The fast path writes every member it was compiled with, so with either of these the context writes from the metadata. The output is the same as the reflection resolver's.
- **The write fast path is compiled for the attribute's values.** The naming policies, `DefaultPropertyMapping`, and `IncludeFields` fix the names and the choice of members in the write fast path. When you pass options to the constructor that differ in one of them, the fast path isn't used: a context in the default mode writes from the metadata and follows your options.
- **The output uses `Environment.NewLine` and the default layout.** The attribute has no `NewLine`, `EmptyElementStyle`, `AttributeStyle`, or `AttributesPerLine` property. Pass options to the constructor to choose the line ending, the form of an empty element, or the layout of attributes.
