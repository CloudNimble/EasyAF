## Summary

Provides XML serialization-related metadata about a property or field. This class cannot be inherited.

## Usage

An `XmlPropertyInfo` describes how one member of an object is mapped: its XML name, whether it's an attribute, an element, or the text of its parent, whether it's required, and the type info of its value. You read these objects from `XmlTypeInfo.Properties`. You don't create them.

```csharp
XmlTypeInfo<Order> metadata = MetadataOrderXmlContext.Default.Order;

output.WriteLine($"Root element: {metadata.RootName.LocalName}");
foreach (XmlPropertyInfo property in metadata.Properties)
{
    string kind = property.IsAttribute ? "attribute" : "element";
    output.WriteLine($"{property.Name.LocalName}: {kind}, {property.PropertyType.Type.Name}");
}
```

The code produces the following output:

```text
Root element: Order
Id: attribute, Int32
Customer: element, String
Line: element, List`1
```

`Name` is the XML name, after attributes and naming policies: the `Lines` property appears as `Line` because of `[XmlElement("Line")]`. `Order` is the explicit order of the member among its siblings, or `-1` when it has none.

The list is filled for a type that the serializer maps member by member, whether the type info comes from the reflection resolver or from a source-generated context in the default mode or in `Metadata` mode. It's empty for type info from a context in `Serialization` mode. The class is read-only. Unlike `JsonPropertyInfo` in System.Text.Json, it can't be used to change a contract.

#### Property Value

Type: `bool`

#### Remarks

A member is nillable when its type is a reference type, a [Nullable`1](https://learn.microsoft.com/dotnet/api/system.nullable-1), or a collection, or when
[XmlElementAttribute.IsNullable](/xmlessentials/api-reference/CloudNimble/Text/Xml/Serialization/XmlElementAttribute#isnullable) is [`true`](https://learn.microsoft.com/dotnet/csharp/language-reference/builtin-types/bool). Whether a [`null`](https://learn.microsoft.com/dotnet/csharp/language-reference/keywords/null) value is written
depends on the ignore condition of the member. When it is written, it is an element marked `xsi:nil="true"`.
