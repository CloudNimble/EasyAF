## Summary

Specifies the element name of the items of type *T* in a collection member. This class cannot be inherited.

## Usage

Apply `[XmlArrayItem]` together with [`[XmlArray]`](/api-reference/CloudNimble/Text/Xml/Serialization/XmlArrayAttribute) to name the item elements inside the wrapper element of a collection.

```csharp
public sealed class Album
{
    public string? Title { get; set; }

    [XmlArray("Tracks")]
    [XmlArrayItem("Track")]
    public List<string>? Tracks { get; set; }
}
```

```csharp
var album = new Album { Title = "Kind of Blue", Tracks = ["So What", "Freddie Freeloader"] };
var options = new XmlSerializerOptions { WriteIndented = true, NewLine = "\n", OmitXmlDeclaration = true };

string xml = XmlSerializer.Serialize(album, options);
output.WriteLine(xml);
```

The code produces the following output:

```xml
<Album>
  <Title>Kind of Blue</Title>
  <Tracks>
    <Track>So What</Track>
    <Track>Freddie Freeloader</Track>
  </Tracks>
</Album>
```

[View the complete sample on GitHub](https://github.com/CloudNimble/XmlEssentials/blob/main/src/CloudNimble.XmlEssentials.Samples/12_SerializeCollections.cs)

## Type Parameters

- `T` - The type of the items that the element name applies to.

## Considerations

- The attribute has an effect only on a wrapped collection: one with `[XmlArray]`, or one that `DefaultCollectionMapping = XmlCollectionMapping.Wrapped` wraps. On a collection with no wrapper, the repeated elements keep the member's name. To rename those, use `[XmlElement("Name")]` or `[XmlPropertyName("Name")]` on the member.
- Without the attribute, each item of a wrapped collection is named after its type: `int`, `string`, and the other XML Schema names for built-in types, and the type's name, converted by the element naming policy, otherwise.
- A name set here isn't converted by a naming policy.
- `Namespace` is the namespace of the items of a collection in a wrapper, which is a member with `[XmlArray]`. Left `null`, an item is written under its name alone, so it is in the namespace of its wrapper when the wrapper has one. An empty string puts the items in no namespace (`xmlns=""`). This is what `System.Xml.Serialization` writes.
- With no wrapper the item is the element of the member, so `Namespace` names nothing: the item has the namespace of the member.
- When a collection is read, every element in the wrapper is an item, whatever its name and namespace.
- For collections whose items are of different derived types, see [Polymorphism](/xmlessentials/guides/polymorphism).

Gets or sets the namespace URI of the item elements.

#### Syntax

```csharp
public string Namespace { get; set; }
```

#### Property Value

Type: `string?`
The namespace URI of the item elements. The default is [`null`](https://learn.microsoft.com/dotnet/csharp/language-reference/keywords/null), which writes an item
under its name alone, so it is in the default namespace that is in scope: the namespace of the wrapper
when the wrapper has one. An empty string puts the items in no namespace.

#### Remarks

The value applies to the items of a collection in a wrapper, which is a member with
[XmlArrayAttribute](/xmlessentials/api-reference/CloudNimble/Text/Xml/Serialization/XmlArrayAttribute). With no wrapper an item is the element of the member, and has the
namespace of the member.

The value is used when the items are written. When they are read, every element in the wrapper is an
item, whatever its name and namespace.
