## Summary

Specifies the order in which a property or field is written among the members of a type, including inherited members.
This class cannot be inherited.

## Usage

Apply `[XmlPropertyOrder]` to a property or field to set where it is written among the members of its type. It is the counterpart of `[JsonPropertyOrder]`. Many XML schemas require elements in a fixed sequence, and this attribute lets you match one without rearranging your class.

```csharp
public sealed class Address
{
    public string? PostalCode { get; set; }

    [XmlPropertyOrder(1)]
    public string? City { get; set; }

    [XmlPropertyOrder(0)]
    public string? Street { get; set; }
}
```

```csharp
var address = new Address { PostalCode = "98052", City = "Redmond", Street = "1 Main St" };
var options = new XmlSerializerOptions { OmitXmlDeclaration = true };

string xml = XmlSerializer.Serialize(address, options);
output.WriteLine(xml);
```

The code produces the following output:

```xml
<Address><Street>1 Main St</Street><City>Redmond</City><PostalCode>98052</PostalCode></Address>
```

[View the complete sample on GitHub](https://github.com/CloudNimble/XmlEssentials/blob/main/src/CloudNimble.XmlEssentials.Samples/08_CustomizeNames.cs)

Members with an order of zero or more are written first, lowest number first. Members with no order follow in declaration order, base class members before derived class members.

## Remarks

Members with an order greater than or equal to zero are written first, sorted by that value. Members with a negative
order, or with no order, follow in declaration order from the most-base type to the most-derived type. Ordering
applies within each kind of member: attributes are written first, then text content, then child elements.
This attribute is analogous to `JsonPropertyOrderAttribute` in `System.Text.Json`.

## Considerations

- A negative order means "not set". This differs from `[JsonPropertyOrder]`, where a negative number places a property before the unordered ones. To put a member first, give it `0` and give the others higher numbers, or leave the others without an order.
- The order covers the whole type, base classes included. A member of a derived class can be placed between two members of its base class, which `System.Xml.Serialization.XmlSerializer` can't do.
- XML attributes are always written before element text, and element text before child elements. The order sorts members within each of those groups.
- Members with the same order keep their declaration order.
- The order affects writing only. When reading, elements are accepted in any order.
- `[XmlPropertyOrder]` takes precedence over the `Order` property of `[XmlElement]` and `[XmlArray]`.
