## Summary

Specifies the built-in [XmlNamingPolicy](/xmlessentials/api-reference/CloudNimble/Text/Xml/XmlNamingPolicy) that a source-generated context uses at run time.

## Usage

`XmlKnownNamingPolicy` names the built-in naming policies as an enumeration, so that you can choose one in an attribute. An attribute argument has to be a compile-time constant, and an [`XmlNamingPolicy`](/xmlessentials/api-reference/CloudNimble/Text/Xml/XmlNamingPolicy) instance isn't one.

It is the type of the `PropertyNamingPolicy`, `ElementNamingPolicy`, and `AttributeNamingPolicy` properties of [`XmlSourceGenerationOptionsAttribute`](/xmlessentials/api-reference/CloudNimble/Text/Xml/Serialization/XmlSourceGenerationOptionsAttribute). It is the counterpart of `JsonKnownNamingPolicy`.

| Value | Policy | `StreetAddress` becomes |
| --- | --- | --- |
| `Unspecified` | None. Names are unchanged. | `StreetAddress` |
| `CamelCase` | `XmlNamingPolicy.CamelCase` | `streetAddress` |
| `SnakeCaseLower` | `XmlNamingPolicy.SnakeCaseLower` | `street_address` |
| `SnakeCaseUpper` | `XmlNamingPolicy.SnakeCaseUpper` | `STREET_ADDRESS` |
| `KebabCaseLower` | `XmlNamingPolicy.KebabCaseLower` | `street-address` |
| `KebabCaseUpper` | `XmlNamingPolicy.KebabCaseUpper` | `STREET-ADDRESS` |
| `PascalCase` | `XmlNamingPolicy.PascalCase` | `StreetAddress` |

When you set options in code instead, assign an `XmlNamingPolicy` to `XmlSerializerOptions` directly. See [Use source generation](/xmlessentials/guides/source-generation) and [Customize names and shape](/xmlessentials/guides/customize-names#use-a-naming-policy-for-all-names).

## Remarks

The values are selected through the naming policy properties of [XmlSourceGenerationOptionsAttribute](/xmlessentials/api-reference/CloudNimble/Text/Xml/Serialization/XmlSourceGenerationOptionsAttribute).
