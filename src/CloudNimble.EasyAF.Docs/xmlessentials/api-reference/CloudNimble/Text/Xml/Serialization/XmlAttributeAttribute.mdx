## Summary

Specifies that a member is serialized as an XML attribute. This class cannot be inherited.

## Usage

Apply `[XmlAttribute]` to a property or field to write it as an XML attribute of the element that represents the object, instead of as a child element. Pass a name to the constructor to name the attribute, and set `Namespace` to put it in a namespace.

```csharp
public sealed class Price
{
    [XmlAttribute]
    public string? Currency { get; set; }

    [XmlText]
    public decimal Amount { get; set; }
}

public sealed class Listing
{
    public string? Name { get; set; }

    public Price? Price { get; set; }
}
```

```csharp
var listing = new Listing
{
    Name = "Keyboard",
    Price = new Price { Currency = "USD", Amount = 49.95m },
};

var options = new XmlSerializerOptions { OmitXmlDeclaration = true };

string xml = XmlSerializer.Serialize(listing, options);
output.WriteLine(xml);
```

The code produces the following output:

```xml
<Listing><Name>Keyboard</Name><Price Currency="USD">49.95</Price></Listing>
```

[View the complete sample on GitHub](https://github.com/CloudNimble/XmlEssentials/blob/main/src/CloudNimble.XmlEssentials.Samples/08_CustomizeNames.cs)

To write every simple member as an attribute without annotating each one, set `XmlSerializerOptions.DefaultPropertyMapping` to `XmlPropertyMapping.Attribute`.

## Remarks

The member must have a simple type: a type with a built-in value converter, an enumeration, or the nullable form of
either. A member of any other type cannot be serialized as an XML attribute.

## Considerations

- Only a simple value can be an XML attribute: a string, a number, a Boolean, a date or time, a GUID, a URI, an enumeration, and the nullable forms of those. On a member of any other type, such as an object or a collection, the serializer throws a `NotSupportedException` the first time the type is used.
- A `null` value is left out. An attribute can't be marked nil.
- Attributes are written before element text and child elements. Among themselves they follow declaration order, or `[XmlPropertyOrder]` when it is set.
- `[XmlPropertyName]` on the same member takes precedence over `AttributeName`. When neither is set, the member name is converted by `AttributeNamingPolicy`, or by `PropertyNamingPolicy` when that is `null`.
- `[XmlAttribute]` can't be combined with `[XmlElement]`, `[XmlText]`, or `[XmlCData]` on one member.
- Characters that aren't allowed in an attribute value, such as `"`, `<`, and `&`, are escaped when written and restored when read.
