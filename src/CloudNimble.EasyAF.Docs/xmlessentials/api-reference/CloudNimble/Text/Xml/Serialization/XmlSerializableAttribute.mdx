## Summary

Instructs the XmlEssentials source generator to generate source code for serializing and deserializing instances of
the specified type and the types in its object graph. This class cannot be inherited.

## Usage

Apply `[XmlSerializable]` to a partial class that derives from `XmlSerializerContext`, once for each type you pass to the serializer. The source generator reads the attributes at compile time and adds a matching `XmlTypeInfo<T>` property to the class.

```csharp
[XmlSerializable<Order>]
public partial class OrderXmlContext : XmlSerializerContext
{
}
```

List the root types only. The generator follows the properties of each type, so listing `Order` also covers the `OrderLine` type of its `Lines` property, and the context gets an `OrderLine` property too.

The generated property is named after the type. Set `TypeInfoPropertyName` to choose another name, for example when two listed types have the same name in different namespaces:

```csharp
[XmlSerializable<OrderLine>(TypeInfoPropertyName = "Line")]
public partial class OrderLineXmlContext : XmlSerializerContext
{
}
```

```csharp
var line = new OrderLine { Sku = "KB-01", Quantity = 1 };

string xml = XmlSerializer.Serialize(line, OrderLineXmlContext.Default.Line);
output.WriteLine(xml);
```

The code produces the following output:

```xml
<?xml version="1.0" encoding="utf-8"?><OrderLine><Quantity>1</Quantity><Sku>KB-01</Sku></OrderLine>
```

[View the complete sample on GitHub](https://github.com/CloudNimble/XmlEssentials/blob/main/src/CloudNimble.XmlEssentials.Samples/32_UseSourceGeneration.cs)

The attribute is the counterpart of `JsonSerializableAttribute` in System.Text.Json.

## Remarks

Place the attribute on a partial class that derives from [XmlSerializerContext](/xmlessentials/api-reference/CloudNimble/Text/Xml/Serialization/XmlSerializerContext). The type is a type
argument, so the compiler checks it and it may be any closed type, an array or a collection included. This attribute
is analogous to `JsonSerializableAttribute` in `System.Text.Json`, which takes the type as a constructor
argument.

## Type Parameters

- `T` - The type to generate source code for.

## Examples

```csharp
[XmlSerializable<Person>]
[XmlSerializable<Person[]>]
[XmlSerializable<Dictionary<string, Person>>(TypeInfoPropertyName = "PeopleByName")]
internal partial class AppXmlContext : XmlSerializerContext
{
}
```

## Considerations

- **The class must be `partial` and derive from `XmlSerializerContext`.** Otherwise the generator reports `XMLESS001`.
- **`GenerationMode` overrides the mode of the context for the listed type.** A value other than `Default` applies to the type the attribute lists. A type listed with `Default`, and a type the generator reaches from a listed type, takes the mode from `[XmlSourceGenerationOptions]` on the context.
- **Metadata and a write fast path are generated only for object types.** For an enumeration, a collection, or a dictionary you list, such as `List<Order>`, the property returns type info that the runtime library creates from the type arguments the generator names, with no reflection. For a simple value you list, such as `int`, the property returns the built-in type info.
- **A listed type is checked at compile time.** See [Understand the diagnostics](/xmlessentials/guides/source-generation#understand-the-diagnostics) for the errors the generator reports.
- **The attribute does nothing at run time.** The reflection resolver doesn't read it.

#### Syntax

```csharp
public CloudNimble.Text.Xml.Serialization.XmlSourceGenerationMode GenerationMode { get; set; }
```

#### Property Value

Type: `CloudNimble.Text.Xml.Serialization.XmlSourceGenerationMode`
A bitwise combination of the enumeration values that specifies what is generated for the type. The default is
[XmlSourceGenerationMode.Default](/xmlessentials/api-reference/CloudNimble/Text/Xml/Serialization/XmlSourceGenerationMode).

#### Remarks

A value other than [XmlSourceGenerationMode.Default](/xmlessentials/api-reference/CloudNimble/Text/Xml/Serialization/XmlSourceGenerationMode) overrides the
[XmlSourceGenerationOptionsAttribute.GenerationMode](/xmlessentials/api-reference/CloudNimble/Text/Xml/Serialization/XmlSourceGenerationOptionsAttribute#generationmode) of the context for this type. The types reached
from it take the mode of the context.
