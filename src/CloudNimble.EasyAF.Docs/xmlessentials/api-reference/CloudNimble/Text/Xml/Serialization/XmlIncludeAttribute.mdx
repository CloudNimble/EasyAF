## Summary

Indicates that a non-public property or field is included for serialization and deserialization, and that a
set accessor that is not public is used when reading. This class cannot be inherited.

## Usage

By default, the serializer maps public properties, and public fields when `XmlSerializerOptions.IncludeFields` is `true`. Put `[XmlInclude]` on a property or field that isn't public to serialize it as well. It is the counterpart of `[JsonInclude]`.

```csharp
public sealed class Account
{
    public string? Name { get; set; }

    [XmlInclude]
    internal string? LedgerCode { get; set; }
}
```

```csharp
var options = new XmlSerializerOptions { OmitXmlDeclaration = true };
var account = new Account { Name = "Operations", LedgerCode = "OPS-17" };

output.WriteLine(XmlSerializer.Serialize(account, options));
```

The code produces the following output:

```xml
<Account><Name>Operations</Name><LedgerCode>OPS-17</LedgerCode></Account>
```

[View the complete sample on GitHub](https://github.com/CloudNimble/XmlEssentials/blob/main/src/CloudNimble.XmlEssentials.Samples/16_Polymorphism.cs)

## Remarks

A public property whose `set` or `init` accessor is not public is written
and is not set when a document is read, as a property with no setter is. Mark it with this attribute to
have the accessor used.

This attribute is analogous to `JsonIncludeAttribute` in `System.Text.Json`. It is not the
`System.Xml.Serialization.XmlIncludeAttribute` of the base class library, which declares known types.
Use `XmlDerivedTypeAttribute`1` to declare a derived type.

## Considerations

- This attribute is not the `XmlIncludeAttribute` of `System.Xml.Serialization`, which declares a known derived type. To declare derived types, use `[XmlDerivedType<T>]`.
- The attribute can be applied to properties and fields only.
- A public property whose `set` or `init` accessor isn't public is written, but isn't set when a document is read, as a property with no setter isn't. Mark it with `[XmlInclude]` to have the accessor used. This is the rule of `[JsonInclude]`.
- An included member is named, ordered, and mapped like a public one, and the other mapping attributes can be combined with it.
