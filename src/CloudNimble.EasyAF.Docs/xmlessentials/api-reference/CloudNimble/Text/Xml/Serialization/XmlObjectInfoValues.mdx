## Summary

Provides serialization metadata about an object type with constructors, properties, and fields. This class
cannot be inherited.

## Remarks

Source-generated contexts create instances of this class and pass them to
[XmlMetadataServices.CreateObjectInfo](/xmlessentials/api-reference/CloudNimble/Text/Xml/Serialization/XmlMetadataServices#createobjectinfo). It is analogous to `JsonObjectInfoValues<T>` in
`System.Text.Json`. The serializer reads and writes the type from this metadata with the rules it applies
to a type it maps through reflection, and with no reflection over the members of the type.

## Type Parameters

- `T` - The object type to serialize or deserialize.

#### Property Value

Type: `System.Func<CloudNimble.Text.Xml.XmlSerializerOptions, CloudNimble.Text.Xml.Serialization.XmlPropertyInfoValues[]>?`
A method that returns one [XmlPropertyInfoValues](/xmlessentials/api-reference/CloudNimble/Text/Xml/Serialization/XmlPropertyInfoValues) for each property and field of the type and

#### Property Value

Type: `System.Action<CloudNimble.Text.Xml.Utf8XmlWriter, T, CloudNimble.Text.Xml.XmlSerializerOptions>?`
A method that writes the attributes and the content of the element for a value, or [`null`](https://learn.microsoft.com/dotnet/csharp/language-reference/keywords/null).
The start and end tags are written by the serializer.

#### Remarks

A source-generated context sets this only when [XmlMetadataServices.CanUseSerializeHandler](/xmlessentials/api-reference/CloudNimble/Text/Xml/Serialization/XmlMetadataServices#canuseserializehandler)
says the options allow it. When it is set, the serializer writes through it. When
[XmlObjectInfoValues`1.PropertyMetadataInitializer](/xmlessentials/api-reference/CloudNimble/Text/Xml/Serialization/XmlObjectInfoValues#propertymetadatainitializer) is [`null`](https://learn.microsoft.com/dotnet/csharp/language-reference/keywords/null) as well, the type has no metadata: it can
be written through this method and cannot be read.
