## Summary

Specifies how a [Char](https://learn.microsoft.com/dotnet/api/system.char) is written and read.

## Values

| Name | Value | Description |
|------|-------|-------------|
| `Character` | 0 | The character itself, such as `a`. This is the default. |
| `Number` | 1 | The number of the character's UTF-16 code unit, such as `97` for `a`. This is what
`System.Xml.Serialization.XmlSerializer` writes. |
