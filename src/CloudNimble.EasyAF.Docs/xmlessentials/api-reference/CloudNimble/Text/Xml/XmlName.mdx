## Summary

Represents a namespace-qualified XML name: a local name, a namespace URI, and an optional prefix.

## Usage

An `XmlName` is a qualified XML name: a local name, a namespace URI, and an optional prefix. The library uses it wherever a name has to carry its namespace, for example `XmlTypeInfo.RootName`, `XmlPropertyInfo.Name`, and the keys of `XmlExtensionData.Attributes`.

Create a name with the local name alone, or add the namespace URI and the prefix:

```csharp
var written = new XmlName("Invoice", "urn:example:billing", "b");
var expected = new XmlName("Invoice", "urn:example:billing");
var unqualified = new XmlName("Invoice");
```

Two names are equal when their local names and namespace URIs are equal. The prefix is kept so that a name can be written the way it was read, and it plays no part in equality or in hash codes.

## Remarks

Two names are equal when [XmlName.LocalName](/xmlessentials/api-reference/CloudNimble/Text/Xml/XmlName#localname) and [XmlName.NamespaceUri](/xmlessentials/api-reference/CloudNimble/Text/Xml/XmlName#namespaceuri) are equal by ordinal comparison.
[XmlName.Prefix](/xmlessentials/api-reference/CloudNimble/Text/Xml/XmlName#prefix) only affects how the name is written. It is not used for equality or for mapping.

## Examples

### Compare and print names

`ToString` returns `prefix:local` when the name has a prefix, `{uri}local` when it has a namespace and no prefix, and the local name otherwise.

```csharp
var written = new XmlName("Invoice", "urn:example:billing", "b");
var expected = new XmlName("Invoice", "urn:example:billing");
var unqualified = new XmlName("Invoice");

output.WriteLine(written);
output.WriteLine(expected);
output.WriteLine(unqualified);
output.WriteLine(written == expected);
output.WriteLine(written == unqualified);
```

The code produces the following output:

```text
b:Invoice
{urn:example:billing}Invoice
Invoice
True
False
```

## Considerations

- `XmlName` is a `readonly struct` that holds three string references. Copying it is cheap, and creating one allocates nothing beyond the strings you pass in.
- The constructor checks only that the local name isn't `null`, empty, or white space. It doesn't check that the parts are valid XML names.
- A `null` namespace URI or prefix passed to the constructor becomes an empty string, so `NamespaceUri` and `Prefix` are never `null` in a name you create.
- Comparison is ordinal. Namespace URIs are compared character by character, as the Namespaces in XML recommendation requires, so `urn:Example` and `urn:example` are different namespaces.
- The output of `ToString` is for display. The `{uri}local` form is not XML syntax.
- `default(XmlName)` doesn't go through the constructor, so its `LocalName`, `NamespaceUri`, and `Prefix` are all `null`. Don't use it as a name.

#### Parameters

| Name | Type | Description |
|------|------|-------------|
| `localName` | `string` | The local name. It cannot be [`null`](https://learn.microsoft.com/dotnet/csharp/language-reference/keywords/null), empty, or white space. |
| `namespaceUri` | `string?` | The namespace URI, or [`null`](https://learn.microsoft.com/dotnet/csharp/language-reference/keywords/null) for no namespace. The default is [`null`](https://learn.microsoft.com/dotnet/csharp/language-reference/keywords/null). |
| `prefix` | `string?` | The prefix, or [`null`](https://learn.microsoft.com/dotnet/csharp/language-reference/keywords/null) for none. The default is [`null`](https://learn.microsoft.com/dotnet/csharp/language-reference/keywords/null). The prefix is not used for equality. |

#### Exceptions

| Exception | Description |
|-----------|-------------|
| `ArgumentNullException` | *localName* is [`null`](https://learn.microsoft.com/dotnet/csharp/language-reference/keywords/null). |
| `ArgumentException` | *localName* is empty or consists only of white-space characters. |

#### Examples

```csharp
var name = new XmlName("Person", "https://example.com", "e");
Console.WriteLine(name); // e:Person
```

#### Remarks

Pass a namespace URI without a prefix when the name is only compared with other names.
[XmlName.ToString](/xmlessentials/api-reference/CloudNimble/Text/Xml/XmlName#tostring) writes the prefix only when it is not empty.
