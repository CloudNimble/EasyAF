## Summary

Represents a mutable XML text node. This class cannot be inherited.

## Usage

`XmlTextNode` is character data inside an element. `Value` holds the text as you'd read it, not as markup: the characters `<` and `&` are escaped when the node is written. For an element that holds only text, setting `XmlElementNode.InnerText` is shorter than adding a text node. Create text nodes yourself for mixed content, where text sits beside child elements.

```csharp
var note = new XmlElementNode("Note");
note.Add(new XmlCommentNode(" reviewed "));
note.Add(new XmlTextNode("Use ** & ** for bold. "));
note.Add(new XmlCDataNode("**Raw** & unescaped"));
note.Add(new XmlProcessingInstructionNode("print", "copies=\"2\""));
note.AddElement("Signature");

output.WriteLine(note.ToString());

foreach (XmlNode child in note.Children)
{
    output.WriteLine($"{child.GetType().Name}: {child.ValueKind}");
}

output.WriteLine($"InnerText: {note.InnerText}");
```

The code produces the following output:

```text
<Note><!-- reviewed -->Use &lt;b> &amp; &lt;/b> for bold. <![CDATA[**Raw** & unescaped]]><?print copies="2"?><Signature/></Note>
XmlCommentNode: Comment
XmlTextNode: Text
XmlCDataNode: CData
XmlProcessingInstructionNode: ProcessingInstruction
XmlElementNode: Element
InnerText: Use ** & ** for bold. **Raw** & unescaped
```

[View the complete sample on GitHub](https://github.com/CloudNimble/XmlEssentials/blob/main/src/CloudNimble.XmlEssentials.Samples/29_BuildWithXmlNode.cs)

## Considerations

- A tree parsed from an indented document has a text node for each run of white space between elements, because the parser keeps the layout. Those nodes are ordinary `XmlTextNode` instances whose `Value` is white space.
- Entity and character references in parsed text are already expanded in `Value`, and CRLF line ends are already LF.
- A `null` value is stored as an empty string.
- `ToString` on a text node throws an `XmlException` ("Text is not allowed at the document level."), because text can't stand alone as a document. Read `Value`.
- Two text nodes next to each other are written one after the other and read back as one text node.
