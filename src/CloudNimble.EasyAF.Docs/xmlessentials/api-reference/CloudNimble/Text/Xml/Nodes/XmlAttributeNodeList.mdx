## Summary

Represents the ordered list of attributes of an [XmlElementNode](/xmlessentials/api-reference/CloudNimble/Text/Xml/Nodes/XmlElementNode). This class cannot be inherited.

## Usage

`XmlAttributeNodeList` is the type of `XmlElementNode.Attributes`. It's an `IList<XmlAttributeNode>` in document order, with two indexers that find an attribute by name: `Attributes["id"]` matches a local name in any namespace, and `Attributes["language", namespaceUri]` matches one namespace. Both return `null` when there is no such attribute.

```csharp
var order = (XmlElementNode)XmlNode.Parse("""<Order id="1042" status="open" draft="true"/>""")!;

order.SetAttribute("status", "shipped");
order.SetAttribute("carrier", "Contoso Freight");
order.Attributes["id"]!.Value = "1043";

XmlAttributeNode draft = order.Attributes["draft"]!;
order.Attributes.Remove(draft);

output.WriteLine(order.ToString());
```

The code produces the following output:

```xml
<Order id="1043" status="shipped" carrier="Contoso Freight"/>
```

You don't create a list. Every `XmlElementNode` has one.

[View the complete sample on GitHub](https://github.com/CloudNimble/XmlEssentials/blob/main/src/CloudNimble.XmlEssentials.Samples/30_ChangeWithXmlNode.cs)

## Remarks

An attribute can belong to one list at a time. Adding, inserting, or assigning an attribute that
already has a parent throws an [XmlException](/xmlessentials/api-reference/CloudNimble/Text/Xml/XmlException), and [`null`](https://learn.microsoft.com/dotnet/csharp/language-reference/keywords/null) throws an
[ArgumentNullException](https://learn.microsoft.com/dotnet/api/system.argumentnullexception). An attribute that is removed or replaced has no parent afterward.
The list does not check for duplicate names.

## Considerations

- Attributes are written in list order. `Insert` and the index setter let you control that order.
- `Add`, `Insert`, and the index setter throw an `XmlException` when the attribute already belongs to an element. `Remove`, `RemoveAt`, `Clear`, and replacing through the index setter clear the parent of the attribute that leaves the list.
- The list doesn't check for duplicate names. Two attributes with the same name throw "Duplicate attribute." when the element is written. `XmlElementNode.SetAttribute` updates an existing attribute instead of adding a second one.
- The list of a parsed element includes its namespace declarations (`xmlns` and `xmlns:prefix`), so `Count` can be larger than the number of attributes you think of as data.
- The name indexers search the list from the start each time. That's the right trade for the handful of attributes a typical element has.
- Don't change the list while a `foreach` loop enumerates it. After a change, the loop's next step throws an `InvalidOperationException` ("Collection was modified; enumeration operation may not execute."), as a `List<T>` or a `JsonArray` does. Loop over a copy (`list.ToArray()`), or loop by index from the end. Setting an attribute's `Value` changes the attribute, not the list.

The list must not change while it is enumerated. After an attribute is added, inserted, removed, or
replaced, or the list is cleared, the next call to [MoveNext](https://learn.microsoft.com/dotnet/api/system.collections.ienumerator.movenext) throws an
[InvalidOperationException](https://learn.microsoft.com/dotnet/api/system.invalidoperationexception). To change the list in a loop, enumerate a copy of it.
