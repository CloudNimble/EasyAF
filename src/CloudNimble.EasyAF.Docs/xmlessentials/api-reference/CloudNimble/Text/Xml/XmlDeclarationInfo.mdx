## Summary

Represents the XML declaration captured when an [XmlDocument](/xmlessentials/api-reference/CloudNimble/Text/Xml/XmlDocument) is parsed.

## Usage

`XmlDeclarationInfo` is what `XmlDocument` keeps of a document's XML declaration: the version, the encoding, and the `standalone` flag. Read it from `XmlDocument.Declaration`, which is `null` when the document has no declaration.

```csharp
using var document = XmlDocument.Parse("<?xml version=\"1.1\" encoding=\"UTF-8\" standalone=\"yes\"?><Order/>"u8);

if (document.Declaration is XmlDeclarationInfo declaration)
{
    output.WriteLine($"Version: {declaration.Version}");
    output.WriteLine($"Encoding: {declaration.Encoding}");
    output.WriteLine($"Standalone: {declaration.Standalone}");
}

using var bare = XmlDocument.Parse("<Order/>"u8);
output.WriteLine($"A document without a declaration has one: {bare.Declaration.HasValue}");
```

```text
Version: 1.1
Encoding: utf-8
Standalone: True
A document without a declaration has one: False
```

[View the complete sample on GitHub](https://github.com/CloudNimble/XmlEssentials/blob/main/src/CloudNimble.XmlEssentials.Samples/21_ReadMarkupAndHandleErrors.cs)

See [How to use XmlDocument](/xmlessentials/guides/use-xmldocument) for the rest of the document API.

## Remarks

The value is immutable. Mutable trees use `CloudNimble.Text.Xml.Nodes.XmlDeclarationNode` instead.

## Considerations

- **The values are normalized, not copied from the source.** For a parsed document, `Version` is `1.0` or `1.1`, and `Encoding` is always `utf-8`, however the document spelled it. In the example, the source says `UTF-8`.
- **`Standalone` has three states:** `true` for `standalone="yes"`, `false` for `standalone="no"`, and `null` when the declaration doesn't say.
- **A missing declaration isn't an error.** `XmlDocument.Declaration` is `null`, and the document is XML 1.0.
- **`XmlDocument` produces this type; `Utf8XmlReader` reports a token.** The reader reports the declaration as an `XmlTokenType.XmlDeclaration` token, with the version in `Utf8XmlReader.Version` and the pseudo-attributes, as written, in `ValueSpan`.
- **It's an immutable value.** In the tree that you can change, the declaration is a `CloudNimble.Text.Xml.Nodes.XmlDeclarationNode`.
