## Summary

Specifies where the fields of a type come among its members, when
[XmlSerializerOptions.IncludeFields](/api-reference/CloudNimble/Text/Xml/XmlSerializerOptions#includefields) includes them.

## Remarks

Under either value, the members of a base class come before those of a class derived from it, the members
of one kind keep the order they are declared in, and an explicit order on a member takes precedence.

## Values

| Name | Value | Description |
|------|-------|-------------|
| `PropertiesFirst` | 0 | The properties of a class, then its fields. This is the default. |
| `FieldsFirst` | 1 | The fields of a class, then its properties. This is the order
`System.Xml.Serialization.XmlSerializer` writes. |
